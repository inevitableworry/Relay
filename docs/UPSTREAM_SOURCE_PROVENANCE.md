# Upstream source provenance

Relay's initial public source snapshot is derived from the open-source chiaki-ng project at upstream commit:

`43728af2e639fecb8a7af1cd68c29820a40de973`

Original upstream repository: https://github.com/chiaki-ng/chiaki-ng

Earlier project lineage: https://github.com/thestr4ng3r/chiaki

The local Relay development checkout was originally a **shallow checkout** of that upstream commit. Its missing historical parent objects could not be uploaded to the new Relay remote. The initial Relay Git branch therefore starts with a new source snapshot commit, while all upstream source-file copyright statements, inherited licenses, submodule pointers and the repository's `CREDITS.md` are retained. The original upstream's full Git history remains available from its own publicly linked repository.

This snapshot does not claim to have written upstream source files or to be an upstream-authorized release. Future Relay commits and public release tags increase normally from this starting point; no published Relay history was rewritten.
