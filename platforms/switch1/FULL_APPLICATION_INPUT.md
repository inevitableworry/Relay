# Relay Switch 1 full-title launch and input acceptance

Relay's installable Switch build must be generated by `package-nca-title.ps1` with an ExeFS `main.npdm` and NCA application title `0100abcd23450000`, rather than launching `relay-switch1.nro` through Homebrew Menu in applet mode. The NPDM specification at `nsp-title-npdm.json` contains the `application_type` kernel capability and `is_64_bit` application metadata. A packaged NSP does not itself prove normal application runtime, title rights or input function until tested on compatible hardware/emulator.

The requested native input contract covers: handheld touchscreen coordinates, UI tap and swipe navigation, touchscreen interactions in stream mode where supported, paired Joy-Cons, single Joy-Con where compatible with Relay's controls, and a wireless or wired Pro Controller. Preserve face-button positional mapping to PlayStation controls and support D-pad, triggers, both sticks, Start/Select equivalents and disconnect/reconnect. Do not classify an emulator-reported controller as physical Joy-Con or Pro Controller hardware without device-specific testing.

Validation sequence: native build, title NCA packaging, `cargo-nx nx tool hactool --verify`, wireless copy to Samsung Galaxy Tab S11 Ultra `/sdcard/Download/Relay/`, SHA-256 comparison, and only then remove superseded Relay-specific NSP files from `/sdcard/Download/RelaySwitchTest/` and `/sdcard/Download/Relay/`. Do not delete keys, firmware, other games, unrelated NSPs, or any other apps. An NSP on Android is an emulator import file, not an Android-installable APK.

Known limitation: this Switch port has a partial native PBS media/controller path but lacks complete traditional PS Remote Play support. Title integrity and native input compilation do not establish successful live PS5 streaming, touchscreen function on hardware, or full application mode launch until tested.
